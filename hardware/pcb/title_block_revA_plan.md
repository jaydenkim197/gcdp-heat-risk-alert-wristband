## Layout Direction

Use a cleaner engineering-document style:

- Main logo on the left side of the title block.
- Project title large and bold in the top row.
- Subtitle directly under the project title.
- Metadata table on the right:
  - Doc No.
  - Rev
  - Date
  - Drawn By
  - Sheet
- Avoid long file path text in the visible title block.
- Use the Altium document parameters for file path if needed, but keep it small or hide it for presentation screenshots.
